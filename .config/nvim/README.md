## Neovim Configuration 

## Prerequisites

- Neovim
- Packer





## Supermaven for Neovim

it is installed by packer (make sure you have packer installed)
    ```
    https://github.com/supermaven-inc/supermaven-nvim
    ```


## INSTALLATION

    After packer is installed just open Neovim and run `PackerSync` and then restart Neovim 



## Themes
    using retrobox theme inside neovim now 

can be used with `colorscheme retrobox` (already set in init.lua)

#### Toggle Theme
    ```bash
# toggle theme dark
    vim.o.background = 'dark'
    ```

    ```bash
# toggle theme light
    vim.o.background = 'light'
    ```
